# آزمون لایهٔ مستقل ادیتور

تاریخ: ۲۰۲۶-۱۰-۲۳

ادامهٔ نمای کاغذی، ۲۰۲۶-۱۰-۲۴: کنترل‌های مستقل نما، zoom و حالت تمرکز اضافه شدند؛ اسکریپت اکنون ۶۲ تست JavaScript و پنج سناریوی مرورگر اجرا می‌کند. برای محدوده، نتایج و تست دستی جدید، [راهنمای نمای کاغذی](editor-paper-view.fa.md) را بخوانید. شمارش‌ها و توضیح ظاهر در بخش‌های قدیمی این فایل مربوط به اجرای اولیه‌اند، نه تکمیل صفحه‌بندی زنده.

ادامهٔ ۲۰۲۶-۱۰-۲۴: اسکریپت اکنون یک سناریوی سوم برای metadata نسخهٔ محتوا هم اجرا می‌کند. وضعیت جدید ۵۷ تست JavaScript و ۳ سناریوی مرورگر است؛ نتایج ۵۴/۲ پایین، مربوط به اجرای اولیهٔ همین مرحله‌اند. برای تغییرات دیتابیس و هشدار شروع سرویس، [راهنمای نسخه‌بندی محتوا](document-content-versioning.fa.md) را بخوانید.

## نتیجهٔ مورد انتظار این قدم

ظاهر و امکانات اصلی ادیتور همان Tiptap فعلی است. تغییر این قدم، جداشدن موتور از هماهنگ‌کنندهٔ ذخیره، بازبینی و دکمه‌هاست؛ نه افزودن صفحه‌بندی زنده یا ورود Word.

موتور فعال فقط در `ClientApp/editors/default-provider.js` انتخاب می‌شود. رابط عمومی در `editor-session.js` و قرارداد محتوای فعلی در `document-contract.js` قرار دارند. شناسه و نسخهٔ این قرارداد فعلاً داخل مرورگرند؛ دیتابیس و payload ذخیره تغییر نکرده‌اند. برای جزئیات طراحی و محدودیت تعویض موتور، [ADR 0028](../adr/0028-replaceable-editor-adapter.md) را ببینید.

## اجرای خودکار

از ریشهٔ راه‌حل `EtranslateProject`، در PowerShell 7:

```powershell
./tests/ETranslate.EndToEndTests/Verify-EditorAdapter.ps1
```

اسکریپت ابتدا همهٔ تست‌های JavaScript را اجرا و bundle اصلی را از سورس جدید می‌سازد؛ سپس دو سناریوی مرورگر را فعال می‌کند. مرورگر Playwright باید قبلاً در مسیر محلی پروژه نصب شده باشد. مسیر Node را می‌توان با `-NodePath` تعیین کرد؛ نصب یا دریافت خودکار وابستگی در این اسکریپت نداریم.

یک سرور تست یکبارمصرف فقط روی loopback و پورت تصادفی اجرا می‌شود و پس از آزمون بسته می‌شود. پاسخ‌های ذخیره/بازبینی ساختگی‌اند؛ تغییر آدرس پس از ذخیره و بازخوانی، واقعاً از HTTP محلی می‌گذرند. درخواست‌های خارجی مرورگر مسدودند. HTML آزمون ساختگی است، اما JavaScript و CSS همان فایل‌های محصول و CSP همان سیاست محصول است. SQL Server، AppHost، حساب واقعی، فایل مشتری و سرویس خارجی لازم نیست. این تست جای آزمون سراسری با backend واقعی را نمی‌گیرد.

موارد پوشش داده‌شده:

- تغییر provider ساختگی بدون دسترسی میزبان به مدل داخلی؛ رد شناسه/نسخه/ساختار ناشناخته و خروجی غیرمجاز؛ cleanup و منع فرمان پس از dispose.
- حفظ فارسی، ترکی و نیم‌فاصله در JSON؛ بازکردن سند بدون dirty شدن، بدون تغییر رشتهٔ ذخیره‌شده و بدون امکان Undo به صفحهٔ خالی.
- تایپ، bold، Undo/Redo، درج جدول، افزودن/حذف ردیف و ستون، به‌روزرسانی پیش‌نمایش و سقف ۵۰ ردیف/۱۲ ستون.
- قفل ویرایش تا پاسخ ذخیره؛ حفظ JSON هنگام پاسخ ۵۰۳؛ بازگرداندن فقط دکمه‌های مجاز؛ ارسال همان فیلد قبلی و بازخوانی پس از پاسخ موفق شبیه‌سازی‌شده.
- حفظ متن و قفل پس از ۴۰۹؛ آزادشدن درست پس از خطای بازبینی؛ بازبینی ناموفق در نمای فقط‌خواندنی نباید آن را قابل ویرایش کند.
- بازکردن متن خالی قدیمی و باقی‌ماندن JSON ناسازگار در fallback، بدون حذف metadata ناشناخته.

در اجرای عادی `dotnet test`، دو سناریوی مرورگر بدون opt-in skip می‌شوند. تست‌های واحد عادی همچنان اجرا می‌شوند.

اجرای این قدم: ۵۴ آزمون JavaScript و هر دو سناریوی مرورگر پاس شدند. در رگرسیون عادی، ۵۰۶ آزمون Domain و ۲ آزمون Architecture پاس شدند؛ ۲۳ آزمون وابسته به محیط در Domain و یک placeholder سراسری skip ماندند. ساخت کل راه‌حل بدون خطا یا هشدار بود. تست دستی با backend/SQL واقعی در این قدم انجام نشده است.

## تست دستی روی برنامهٔ محلی

با یک پروندهٔ آزمایشی و حساب مجاز، نه سند واقعی مشتری:

1. پرونده را باز کنید؛ صرف کلیک و جابه‌جایی مکان‌نما نباید پیام «تغییر ذخیره‌نشده» ایجاد کند.
2. متن فارسی و ترکی بنویسید، bold و Undo/Redo را امتحان کنید؛ یک جدول بسازید و ردیف/ستون را تغییر دهید.
3. ذخیره کنید و صفحه را دوباره باز کنید؛ متن و جدول باید باقی بمانند و Undo اولیه غیرفعال باشد.
4. در ابتدای متن و سپس داخل جدول کلیک کنید؛ فرمان‌های مربوط به جدول فقط در محل مجاز فعال باشند.
5. نسخهٔ قبلی یا نسخهٔ قفل‌شده برای بازبینی را باز کنید؛ تایپ و فرمان‌های تغییر محتوا غیرفعال بمانند.
6. با دو تب، تعارض نسخه را روی دادهٔ ساختگی بازتولید کنید؛ تب قدیمی باید متن واردشده را نگه دارد و از بازنویسی جلوگیری کند.

تطابق صفحه/PDF، حل ایراد افزونهٔ صفحه‌بندی رایگان، Clipboard واقعی Word، DOCX، فونت/رنگ جدید و مهاجرت قالب محتوا در این قدم پیاده نشده‌اند. هیچ SDK یا حساب تجاری نیز فعال نشده است.
