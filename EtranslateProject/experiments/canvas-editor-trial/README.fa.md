# نمونهٔ مستقل Canvas Editor

نسخهٔ آزمایش‌شده: `@hufe921/canvas-editor@1.0.5`، با مجوز MIT و فقط همان یک وابستگی npm. این نمونه **جایگزین ادیتور سایت نشده** و برای محصول تأیید نیست: مشکل مکان‌نمای فارسی/متن دوزبانه و خروجی چاپ هنوز مانع انتخاب آن‌اند. [گزارش کامل](../../docs/research/canvas-editor-trial.fa.md)

داده‌ها ساختگی و فقط در حافظهٔ تب هستند؛ با refresh پاک می‌شوند. هیچ پرونده، API، SQL Server، قالب تثبیت‌شده یا PDF بایگانی باز یا تغییر نمی‌کند. نصب تجاری، خرید و سرویس تبدیل ابری نداریم.

## اجرا

Node نسخهٔ `24.13.1` یا جدیدتر استفاده کنید؛ این آزمایش با `24.19.0` اجرا شد. در این دستگاه Node سیستم قدیمی‌تر است؛ نسخهٔ سراسری را تغییر ندادیم و runtime همراه را به کار بردیم.

از همین پوشه، در محیط دارای Node/npm مناسب:

```powershell
npm ci --ignore-scripts --no-audit --no-fund
node build.mjs
node serve.mjs --port 5080
```

در این دستگاه برای build و اجرا می‌توان از مسیر کامل استفاده کرد:

```powershell
$trialNode='C:/Users/user/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe'
& $trialNode build.mjs
& $trialNode serve.mjs --port 5080
```

اگر نصب بسته را هم با همین runtime انجام می‌دهید، npm CLI موجود را با آن اجرا کنید، نه npm.cmd متصل به Node قدیمی:

```powershell
& $trialNode 'C:/Program Files/nodejs/node_modules/npm/bin/npm-cli.js' ci --ignore-scripts --no-audit --no-fund
```

وابستگی‌های Web موجود برای ابزار build لازم‌اند؛ بسته‌های Web تغییر نمی‌کنند. سپس `http://127.0.0.1:5080` را باز کنید. توقف سرور دستی: `Ctrl+C` در ترمینال مربوط.

## چه چیزهایی را امتحان کنیم؟

1. حالت اول: بالای صفحه، «سلام دنیا» و متن مخلوط با نمایش طبیعی مرورگر دیده می‌شود؛ پایین آن همان متن در Canvas است. اتصال ظاهری حروف را با ترتیب عبارت‌ها و مکان‌نما اشتباه نگیرید. داخل واژهٔ فارسی کلیک و حرکت مکان‌نما را امتحان کنید؛ این بخش تأیید نشده است.
2. `48 paragraflı belge`: چهار صفحهٔ قابل‌ویرایش، شماره و بازگشت به صفحات. متن فارسی/ترکی و نیم‌فاصله در داده حفظ شدند.
3. Undo/Redo و بزرگ‌نمایی ۷۵/۱۰۰/۱۲۵ درصد. بازخوانی `Bellekte yeniden aç` فقط JSON حافظهٔ همان تب را دوباره باز می‌کند، ذخیرهٔ پایدار نیست.
4. جدول ۴۶ ردیفی، سلول ادغام‌شده، سلول بلند و پاراگراف بلند. نمونه‌های ما به ترتیب ۴، ۱، ۳ و ۵ صفحه شدند. این تأیید همهٔ جدول‌ها، زبان‌ها و فایل‌ها نیست.
5. `Word benzeri sabit HTML`: ورود یک رشتهٔ HTML ثابت، نه Clipboard Word یا فایل DOCX واقعی. برخی اندازه‌ها، رنگ، تراز و bold/italic حفظ شدند؛ فونت Arial در دادهٔ خروجی حفظ نشد.

Paste، Drop و منوی راست‌کلیک عمومی برای جلوگیری از ورود فایل/نشانی خارج از محدوده مسدودند. از سند واقعی یا اطلاعات مشتری استفاده نکنید. راست‌چین کردن فقط تراز است؛ دکمهٔ «RTL» ساختگی به آن اضافه نشده است.

## آزمون خودکار

از پوشهٔ `EtranslateProject`:

```powershell
./tests/ETranslate.EndToEndTests/Verify-CanvasEditorTrial.ps1
```

مسیر Node و Python با `-NodePath` و `-PythonPath` قابل تغییر است. Python دارای pypdf و Chromium محلی `.local/pdf-browsers` لازم‌اند. WSL، Docker، Aspire و SQL Server لازم نیست. سرور متعلق به تست در پایان بسته می‌شود.

۴ آزمون fixture و یک آزمون مرورگر اجرا می‌شوند. گزارش و تصاویر در `tmp/canvas-editor-trial` هستند. خروجی دو مسیر چاپ با pypdf مقایسه می‌شود: تصویر صفحه‌ها داخل PDF و HTML صادرشده در Chromium. **پاس شدن آزمون ابزار به معنی تأیید کیفیت موتور نیست.** در اجرای نهایی، PDF تصویری صفر نویسهٔ قابل‌استخراج داشت و PDF مبتنی بر HTML به‌جای چهار صفحه، سه صفحه شد.

آزمون علاوه بر وجود متن در JSON، رسم نشانگر انتهایی جدول/سلول و هر ۴۶ شمارهٔ ردیف را بررسی می‌کند. تصاویر همهٔ صفحات این نمونه‌ها هم در خروجی توسعه ذخیره می‌شوند. خطا یا timeout آزمون را با گزارش باقی‌مانده از اجرای قبلی اشتباه نگیرید.

## مرز امنیتی و فنی

- سرور loopback با GET/HEAD و فهرست صریح فایل‌هاست؛ POST، مسیر دلخواه، ذخیره یا upload ندارد.
- اتصال خارجی بسته است. فقط style درون‌صفحه‌ای، تصویر `data:` و worker باندل‌شدهٔ `blob:` برای نیازهای خود کتابخانه در CSP این نمونه مجازند؛ سیاست امنیتی سایت اصلی تغییر نکرده است.
- برای حفظ تاریخچه از لحظهٔ باز شدن، یک snapshot اولیه از طریق `executeForceUpdate` رسمی ثبت شد؛ سورس vendor patch نشده است.
- HTML ثابت بدون URL، اسکریپت، تصویر یا iframe استفاده می‌شود؛ این کد واردکنندهٔ عمومی و امن Word نیست.
- JSON بومی Canvas با Tiptap فعلی متفاوت است؛ هیچ adapter، migration، ذخیرهٔ پرونده یا قفل قالبی پیاده نشده است.
- LICENSE/README کتابخانه و OFL فونت‌های موجود کنار bundle حفظ می‌شوند. هیچ وابستگی DOCX یا شاخهٔ جداگانهٔ PDF نصب نشده است.
