# آزمایش مستقل انتخاب موتور ادیتور

این ابزار محصول نهایی نیست. فقط Tiptap پایهٔ نصب‌شده را با دادهٔ ساختگی می‌سنجد؛ SDK تجاری نصب یا فعال نمی‌کند و هیچ API، دیتابیس یا سند واقعی را باز نمی‌کند. سمت چپ متن قابل‌ویرایش و سمت راست اندازه‌گیری فقط‌خواندنیِ بلوک‌هاست؛ صفحه‌بندی قابل‌ویرایش و شکست پاراگراف/جدول پیاده نشده‌اند.

از پوشهٔ `EtranslateProject`:

```powershell
node ./experiments/editor-engine-step1/build.mjs
node ./experiments/editor-engine-step1/serve.mjs --port 5078
```

سپس `http://127.0.0.1:5078` را باز کنید. اگر Node روی PATH نیست، از مسیر Node نصب‌شده یا runtime همراه Codex استفاده کنید. وابستگی‌های نصب‌شدهٔ Web لازم‌اند؛ خود نمونه چیزی نصب نمی‌کند. برای توقف سرور همان ترمینال `Ctrl+C` کافی است.

در `Sentetik örnek` یکی از چهار حالت را انتخاب و `Örneği yükle` را بزنید. `Ölçümü yenile` اندازه‌گیری را تازه می‌کند؛ دکمه‌های شماره، به پیش‌نمایش صفحه‌ها می‌روند. `Önizleme ölçeği` اندازهٔ دیدن کاغذ را تغییر می‌دهد، نه دادهٔ سند. در پنل باریک، اسکرول داخلی عمداً حفظ شده تا اندازهٔ کاغذ با عرض مرورگر تغییر نکند.

از Paste اسناد واقعی استفاده نکنید؛ Paste و Drop در این آزمایش مسدودند. نمونهٔ Word صرفاً HTML ثابت است و آزمایش Clipboard یا ورود DOCX نیست. محتوا فقط در حافظهٔ تب است و با بازخوانی پاک می‌شود؛ ذخیرهٔ فایل یا localStorage وجود ندارد.

سرور فقط روی loopback گوش می‌دهد، فایل‌های مشخص HTML/JS/CSS/font را با فهرست مجاز می‌فرستد و POST یا مسیر دلخواه ندارد. CSP ارتباط بیرونی را مسدود می‌کند. آن را به شبکهٔ عمومی یا سایت اصلی منتشر نکنید.

## آزمون قابل تکرار

پس از ساخت .NET راهکار، از پوشهٔ `EtranslateProject`:

```powershell
./tests/ETranslate.EndToEndTests/Verify-EditorEngineStep1.ps1
```

در صورت نیاز `-NodePath` را به مسیر اجرایی Node بدهید. Chromium محلیِ تست نیز باید موجود باشد. این تست به Aspire، SQL Server یا Docker نیاز ندارد؛ سرور موقت خودش را پس از پایان می‌بندد.

چهار آزمون fixture و یک آزمون مرورگر/PDF اجرا می‌شوند. PDF مرجع فقط با چاپ‌گر موجود و دادهٔ ساختگی ساخته می‌شود. گزارش و تصاویر در `tmp/editor-engine-step1` هستند؛ برابر شدن تعداد صفحات یک نمونه به معنی تضمین یکسان‌بودن تمام شکست‌های صفحه نیست.

مقایسه و پیشنهاد فنی در [گزارش قدم اول](../../docs/research/editor-engine-step1.fa.md) است.
