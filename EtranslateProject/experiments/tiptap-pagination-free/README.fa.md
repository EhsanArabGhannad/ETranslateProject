# آزمایش رایگان صفحه‌بندی قابل‌ویرایش

این صفحه مستقل از سایت اصلی است: Tiptap موجود `3.31.4` با `tiptap-pagination-plus@3.1.0` و `tiptap-table-plus@3.1.0`. داده‌ها ساختگی و فقط در حافظهٔ تب هستند. اسناد مشتری، دیتابیس، قالب‌های تثبیت‌شده، امضاها و PDFهای آرشیو باز یا تغییر داده نمی‌شوند.

**نتیجه: در وضعیت فعلی برای محصول تأیید نشده است.** ویرایش چندصفحه‌ای، رفت‌وبرگشت صفحه و Undo/Redo کار کردند، ولی اختلاف با PDF، تغییر ساختار جدول و ناپایداری سلول بلند مانع اتصال مستقیم‌اند. [گزارش نتایج](../../docs/research/free-pagination-trial.fa.md)

## اجرا

Node باید حداقل `22.13.0` باشد؛ اجرای این بررسی با Node `24.19.0` انجام شد. نسخهٔ Node سیستم این دستگاه `22.12.0` است؛ برای اجرا از runtime جدیدتر استفاده کنید و نسخهٔ سراسری را خودکار تغییر ندهید.

برای اولین آماده‌سازی، از همین پوشهٔ آزمایش:

```powershell
npm ci --ignore-scripts --legacy-peer-deps --no-fund --no-audit
node build.mjs
node serve.mjs --port 5079
```

سپس `http://127.0.0.1:5079` را باز کنید. `Ctrl+C` در ترمینال مربوط، سرور را می‌بندد. اگر Node مناسب روی PATH نیست، executable جدیدتر را با مسیر کامل اجرا کنید؛ مثلاً در این دستگاه:

```powershell
& 'C:/Users/user/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe' build.mjs
& 'C:/Users/user/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe' serve.mjs --port 5079
```

وابستگی‌های نصب‌شدهٔ Web نیز لازم‌اند. `--legacy-peer-deps` اینجا عمداً از نصب خودکار نسخهٔ دیگری از موتور جلوگیری می‌کند: build، موتور و ProseMirror واحد را از Web موجود resolve و نسخه را کنترل می‌کند. این دستور را به نصب بسته‌های سایت اصلی تعمیم ندهید. lockfile فقط همین آزمایش را پوشش می‌دهد. هیچ اسکریپت نصبی اجرا نمی‌شود.

## موارد قابل امتحان

1. نمونهٔ پیش‌فرض متن فارسی/ترکی: چهار صفحه؛ روی شمارهٔ صفحه بزنید، متن را ویرایش کنید و Undo/Redo را امتحان کنید.
2. به صفحهٔ اول برگردید و متن اضافه کنید؛ ادامهٔ سند باید به جلو حرکت کند. در آزمون خودکار با افزودن ۴۰ پاراگراف، تعداد از ۴ به ۶ رسید و با Undo به ۴ برگشت.
3. بزرگ‌نمایی ۷۵/۱۰۰/۱۲۵ درصد؛ داده و selection در آزمون ثابت ماندند. این، تضمین همهٔ مرورگرها نیست.
4. `Bellekte yeniden aç`: بازخوانی JSON همان تب برای آزمون رفت‌وبرگشت؛ ذخیرهٔ پایدار روی سرور نیست. با refresh مرورگر، تغییرها از بین می‌روند.
5. نمونهٔ جدول بلند، سلول ادغام‌شده و سلول بلندتر از صفحه. هشدار ناسازگاری با ساختار فعلی را جدی بگیرید؛ نمونهٔ سلول بلند عمداً شکست افزونه را آشکار می‌کند.
6. نمونهٔ Word فقط HTML ثابت است؛ شش ویژگی قالب‌بندی همچنان از دست می‌روند. Paste واقعی و ورود DOCX در این صفحه پیاده نشده‌اند.

هنگام افزایش ناپایدار صفحات، watchdog مستقل بعد از عبور از آستانهٔ ۵۰، صفحه‌بندی را خاموش می‌کند و متن را نگه می‌دارد. این محافظ آزمایش است، نه رفع اشکال افزونه. برای ادامه یک نمونهٔ دیگر بارگذاری کنید. روی این صفحه سند واقعی Paste یا Drop نکنید؛ هر دو مسدودند.

## آزمون قابل تکرار

از پوشهٔ `EtranslateProject`:

```powershell
./tests/ETranslate.EndToEndTests/Verify-FreePagination.ps1
```

پارامترهای `-NodePath` و `-PythonPath` قابل تنظیم‌اند. Chromium محلی `.local/pdf-browsers`، بسته‌های Web و Python دارای pypdf لازم‌اند. نیازی به SQL Server، Aspire، WSL یا Docker نیست. سرور موقت متعلق به خود تست، در پایان بسته می‌شود.

شش آزمون fixture و یک آزمون مرورگر اجرا می‌شوند؛ سپس ۴۸ نشانگر متنِ PDF مرجع با محلشان در ادیتور مقایسه می‌شود. نتیجه در `tmp/free-pagination/browser-report.json` و `pdf-comparison.json` است. **پاس شدن harness یعنی اندازه‌گیری و حفاظت درست انجام شد، نه اینکه کیفیت موتور تأیید شده باشد.** این اجرا صریحاً شکست سلول بلند و عدم تطابق مرز صفحه را ثبت می‌کند.

## محدودیت امنیتی و مجوز

سرور فقط loopback و GET/HEAD روی فهرست مشخص فایل‌ها دارد؛ مسیر دلخواه، API، upload یا ذخیره ندارد. ارتباط خارجی، تصویر و اسکریپت درون‌صفحه‌ای توسط CSP بسته‌اند. فقط style درون‌صفحه‌ای در این آزمایش مجاز شده، چون افزونه آن را تولید می‌کند؛ CSP محصول تغییر نکرده و این تنظیم نباید به آن کپی شود.

سربرگ/پابرگ ثابت‌اند؛ افزونه محتوا را با `innerHTML` می‌سازد، بنابراین دادهٔ دلخواه کاربر/قالب را مستقیم به آن ندهید. ورودی HTML عمومی یا تصاویر خارجی در این برش وجود ندارند.

دو افزونه در metadata و README خود مجوز MIT اعلام کرده‌اند. نسخه، integrity و نشانی رجیستری در lockfile ثبت و READMEهای منتشرشده همراه bundle آزمایشی حفظ شده‌اند. [Pagination Plus](https://github.com/RomikMakavana/tiptap-pagination-plus)، [Table Plus](https://github.com/RomikMakavana/tiptap-table-plus). اعلان‌های کتابخانه‌های موجود و OFL فونت‌ها هم در `generated` کپی می‌شوند. این بررسی جای ممیزی وابستگی و بررسی کامل اعلان‌های مجوز پیش از توزیع محصول را نمی‌گیرد.
